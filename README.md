#  L'Élégance - Salon de Coiffure Website

Bienvenue sur **L'Élégance**, un site vitrine moderne et élégant conçu pour un salon de coiffure.

Ce projet met en avant les prestations, la galerie, les coiffeurs et un système de réservation interactif.

##  Aperçu du projet

* Présentation du salon
* Mise en avant des prestations
* Galerie des réalisations
* Informations de contact
* Horaires d'ouverture
* Réservation via popup moderne
* Responsive Design

##  Technologies utilisées

* HTML5
* Tailwind CSS
* Alpine.js
* Font Awesome

##  Responsive Design

* Mobile
* Tablette
* Desktop

## ⚠️ Statut du projet

Ce projet est actuellement développé côté **Frontend uniquement**.

Les parties suivantes seront ajoutées prochainement :
* Réservation réelle
* Base de données
* Dashboard Admin
* Authentification
* Notifications Email / WhatsApp
